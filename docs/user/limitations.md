# 尚未实现与已知限制

## 尚未实现

下面这些在设计或代码里出现过，但当前版本没有做，或者没有接通：

- **子代理（多个智能体分工）**：权限和提示词按“可以有子代理”设计过，但现在没有任何入口能创建子代理，模型也没有这样的工具。导入 Claude Code 插件时，其中的子 Agent 部分不会使用。
- **在沙箱里运行命令**：模型的 PowerShell、CMD 和终端以你的 Windows 账户运行，不在沙箱里（见[权限模式与审批](permissions.md)）。代码里有受限账户和 AppContainer 两种隔离执行的设计，但都没有接到任何功能上；受限账户那一套也不随正式版发布。
- **更严格或带引导的安全档位**：权限只有只读、工作区读写、完全访问三种模式。代码里预留的另外两种安全档位不会被使用。
- **中断后的额外提示**：任务中断后可以在同一会话里继续，但 Aura 不会另外告诉模型“刚才中断过、重试过、上下文重建过或重启过”。
- **让模型起草工具**：模型不能起草新的工具或工具包；工具包只能由你在“设置 → 工具”里导入。

## 已知限制

- **命令里的删除只认常见写法**：`Remove-Item`、`del`、`rd`、`git clean -f`、`robocopy /MIR` 等写法，包括写在引号里、`Invoke-Expression` 或 `powershell -c` 里的，会每次问你；用 Python、Node 等脚本间接删除的识别不出来。
- **命令里的联网不受网站规则限制**：网站的允许与阻止只管联网工具和内置浏览器。
- **被 `.gitignore` 忽略的文件夹不进入查找和搜索**：它们在文件树里照常显示，展开时从磁盘现读，模型也能列出和读取其中的文件。
- **Chrome 控制只支持 Chrome**，不能上传或下载文件；扩展要在 Chrome 的开发者模式里加载（见 [Chrome 控制](chrome.md)）。
- **缓存键没有开关**：发往 OpenAI 官方接口和本机网关（如 CLIProxyAPI）的 Responses 请求都带缓存键 `prompt_cache_key`；本机网关不接受这个字段时请求会失败，目前没有关闭它的设置。
- 只支持 Windows 11 x64；安装程序没有代码签名。
- 右侧栏的终端压窄后再拉宽时，终端上部会暂时空白；之前的内容仍在滚动历史里，运行下一条命令后恢复正常。
