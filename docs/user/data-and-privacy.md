# 数据与隐私

## 发出去的内容

- **模型服务**：你的消息、会话上下文、模型读取的文件内容和工具结果，发给你在“设置 → 模型”里配置的服务。
- **联网工具**：只访问你允许的网站，见[权限模式与审批](permissions.md)。模型运行的命令（PowerShell、CMD）不受网站规则限制。
- **检查更新**：向 GitHub（`api.github.com` 与 Releases 的下载地址）询问新版本并下载更新包，请求里只有 Aura 的版本号，不带你的数据。可以在“设置 → 关于与更新”里关闭自动检查。

Aura 不收集使用数据，没有统计或遥测。

## 存在本机的内容

| 内容 | 位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\Aura`（安装时可以改） |
| 会话、日志、更新前的数据备份、Chrome 扩展文件夹 | `%LOCALAPPDATA%\Aura` 下这个安装对应的文件夹 |
| 设置 | `%APPDATA%\Aura` 下这个安装对应的文件夹 |
| API Key、MCP 登录凭据、工具凭据、Chrome 配对密钥 | Windows 凭据管理器 |
| 全局记忆 | `%USERPROFILE%\.aura\memories` |
| 工作区记忆 | 工作区里的 `.memories` 文件夹 |

## 删除

- 在会话列表里可以归档会话；在“设置 → 归档”里恢复或彻底删除。删除会话会删除 Aura 为它保存的全部记录，不会删除工作区里的文件。
- 卸载时可以选择同时删除数据，见[安装、更新与卸载](install-and-update.md)。
