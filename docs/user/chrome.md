# Chrome 控制

模型可以操作你在自己的 Chrome 里共享给它的标签页：读取页面、点击、输入、滚动、截图，也可以在“Aura”标签组里新开标签页。它用的是你 Chrome 里已有的登录状态，所以只碰你共享的标签页，其余标签页它看不到。只支持 Chrome 116 及更新的版本。

## 第一次设置

1. 在 Aura 的“设置 → 网络与浏览器 → Chrome”里打开“Chrome 控制”。
2. 点“打开扩展文件夹”。Aura 把扩展放在它的数据文件夹里（`%LOCALAPPDATA%\Aura` 下这个安装对应的文件夹里的 `chrome\extension`）。
3. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的“开发者模式”，点“加载已解压的扩展程序”，选这个文件夹。
4. 在 Aura 的设置页点“配对”，记下配对码（5 分钟内有效）。在 Chrome 工具栏点 Aura 的图标打开侧边栏，输入配对码，点“配对”。侧边栏显示“已连接”就好了。

Aura 每次启动会把这个文件夹更新到当前版本，Chrome 下次启动时用上新文件；想马上用，可以在 `chrome://extensions` 里点扩展的刷新按钮。配对只需要做一次。

## 共享标签页

- **你来共享**：在要共享的标签页上打开侧边栏，选会话和范围（本会话，或只到这一轮结束），点“共享给 Aura”。
- **模型新开**：模型可以在“Aura”标签组里打开新标签页，打开前会问你这个网站；打开的标签页自动共享给这个会话。

同一时间只有一个会话能操作 Chrome。

## 什么时候会问你

- 工作区读写和完全访问模式下，在共享的标签页里点击、输入不再询问；只读模式下第一次操作会问，可以选“本轮允许”。
- 标签页跳到这个共享还没确认过的网站时，先问你，只能允许一次，允许后这个共享记住它。
- 购买、付款、删除、发送、发布、转账这类操作每次都问，只能允许一次。
- 密码、验证码、支付卡这类字段，验证码页面，以及会打开选择文件窗口的点击，模型都不做。需要时它会把标签页交给你：侧边栏和 Aura 里都会显示它要你做的事，做完点“完成”。

模型操作时，Chrome 会在页面上方显示正在调试的提示条；空闲一分钟后、你自己开始操作这个标签页时，或共享结束时，提示条消失。

## 停止与断开

- Aura 输入框上方的“Chrome · N 个标签页”这一行里点“停止”，或在侧边栏点“停止”：正在执行的操作停下，所有共享结束。
- 设置页的“断开并忘记”删除配对，扩展回到未配对状态。
- 关闭“Chrome 控制”等于断开并忘记，同时删除 Chrome 里找到 Aura 用的注册。

卸载 Aura 时，Chrome 里的注册和扩展文件夹一起删除；之后 Chrome 会提示这个扩展无法加载，在 `chrome://extensions` 里移除它即可。

## 限制

- 只支持 Chrome，不支持 Edge 等其他浏览器。
- 不能上传或下载文件。
- 通行密钥（Passkey）的对话框是 Chrome 自己的，扩展看不到，需要你自己完成。
