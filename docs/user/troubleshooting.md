# 遇到问题时

## Aura 启动失败

- 刚更新后启动失败：Aura 会自动回到上一个版本，并在“设置 → 关于与更新”里说明。
- 短时间内连续崩溃：Aura 显示恢复窗口，可以重启、以安全模式启动，或导出诊断信息。
- 程序文件损坏：重新运行同一版本的安装程序修复，数据不受影响。

## 设置文件损坏

某项设置读不出来时，Aura 用默认值继续运行，并在对应的设置页提示。你可以重试、恢复上一版有效的设置，或重置为默认值；操作前会说明影响范围。保存在凭据管理器里的密钥不受影响。

## 模型请求失败

失败的步骤会显示服务返回的原因和下一步建议，例如检查 Key、网络或代理。任务中断后可以在同一会话里继续。

## 工具调用被拦下

审批被拒绝、权限不够或超出允许的网站时，模型会收到原因。需要时切换权限模式或在审批卡片里同意即可。

## 已知限制

- 只支持 Windows 11 x64。
- 安装程序没有代码签名，SmartScreen 会提示，见[安装](install-and-update.md)。
- 右侧栏的终端压窄后再拉宽时，终端上部会暂时空白；之前的内容仍在滚动历史里，运行下一条命令后恢复正常。

## 报告问题

在 GitHub 的 [Issues](https://github.com/mubai0628/aura/issues) 里描述问题和复现步骤。安全问题请按 [SECURITY.md](../../SECURITY.md) 私下报告。附日志前请确认其中没有你不想公开的内容。
