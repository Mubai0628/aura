# 安装、更新与卸载

## 安装

1. 在 [Releases](https://github.com/mubai0628/aura/releases) 页面下载 `Aura-Setup-<版本>-x64.exe`。同一页的 `SHA256SUMS` 列出每个文件的 SHA-256，可以在 PowerShell 里用 `Get-FileHash <文件>` 核对。
2. 运行安装程序。安装程序没有 Windows 代码签名，SmartScreen 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。
3. 安装程序显示要安装的版本和位置（默认 `%LOCALAPPDATA%\Programs\Aura`，可以改到一个空文件夹），可以选择是否在桌面放快捷方式。安装只针对当前 Windows 用户，不需要管理员权限。

安装后，Aura 出现在开始菜单和 Windows“设置 → 应用”里。

## 更新

Aura 启动约一分钟后检查一次 GitHub 上是否有新版本，之后每天检查一次；在“设置 → 关于与更新”里可以关闭自动检查，或者随时手动检查。检查和下载走 Aura 自己的网络代理设置；没有设置时用系统代理。

发现新版本后，确认下载即可。下载中断后再次下载会从断点继续。下载完成后，新版本先放在旧版本旁边等待，下次启动 Aura（或在页面上点重启）时试运行：

- 新版本正常启动后，它成为当前版本，旧版本保留为“上一个版本”；
- 新版本启动失败，Aura 自动回到旧版本，并在“关于与更新”里说明发生了什么。

更新前，Aura 会把会话和设置的数据库复制一份。新版本试运行失败时，数据会恢复到更新前的样子。

也可以下载新版本的安装程序直接运行，效果与在应用里更新相同。

## 回到上一个版本

“设置 → 关于与更新”里有“回到上一个版本”。可以选择只换回程序，或者同时把数据恢复到更新到当前版本之前的样子（更新之后产生的改动会丢失）。

## 修复

再次运行同一版本的安装程序会修复安装：缺失或损坏的程序文件被换回原样，你的数据不受影响。

## 卸载

在 Windows“设置 → 应用 → 已安装的应用”里找到 Aura，选择卸载。卸载前请先关闭 Aura。

- 默认只删除程序，保留你的数据：会话、设置、记忆和保存在 Windows 凭据管理器里的密钥。之后再安装 Aura 会接着使用这些数据。
- 卸载窗口里可以勾选“同时删除我的数据”：删除 `%LOCALAPPDATA%\Aura` 下这个安装对应的数据文件夹，以及这个 Aura 保存在凭据管理器里的凭据，删除前会再确认一次。工作区里的文件和工作区的 `.memories` 文件夹不会被删除。
