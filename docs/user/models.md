# 模型与服务

Aura 不带模型，你需要接入自己的模型服务。在“设置 → 模型”里管理。

## 添加服务

- 选一个服务类型（如 DeepSeek，或任何 OpenAI 兼容接口），填地址和 API Key。连接的接口格式可以选 OpenAI Responses、OpenAI Chat Completions 或 Anthropic Messages。API Key 只保存在 Windows 凭据管理器里，界面上不再显示原文，也不写进 Aura 的任何文件。
- 一个服务下可以有多个连接（不同的 Key 或地址），可以指定默认连接。
- 保存后，Aura 列出这个服务提供的模型；也可以手动添加模型。

## 模型设置

每个模型可以设置：

- **会话默认思考程度**：新会话用这个模型时的思考档位；“官方默认”表示不指定，由服务决定。
- **图片输入**：接收或不接收。接收时，消息里的图片、截图和视频关键帧会发给这个模型；不接收的模型只收到文字说明。
- 上下文窗口与输出上限：用来判断什么时候需要压缩上下文。上下文窗口一栏显示这个模型实际使用的值；改了以后随“保存 Profile”一起保存，清空则回到目录里的值或默认的 256,000。

## 在会话里选择

输入框下方可以切换这个会话的模型和思考程度。每个会话记住自己的选择；新会话使用设置里的默认值。

## 上下文压缩

对话变长后，Aura 会在下一次请求放不下之前自动压缩：较早的对话整理成摘要，最近的内容保留原文，旧的工具结果先让出空间。也可以随时在输入框输入 `/compact` 手动压缩，后面可以附上希望保留的重点。

## 网络代理

如果访问模型服务需要代理，在“设置 → 工具”的网络代理里填写。Aura 的模型请求、联网工具和检查更新都会使用它；没有设置时使用系统代理。
