# 工具

模型通过工具完成工作，每次调用都显示在会话里，可以展开查看参数和结果。常用工具默认加载；其他工具模型需要时自己搜索并加载。“设置 → 工具”里可以查看全部工具，调整默认加载的工具。

## 文件

读取、列出、查找、搜索、新建、修改文件，以及删除（默认移到回收站）。写入前 Aura 核对文件是否在模型读过之后被改过，避免覆盖你的修改。

被 `.gitignore` 忽略的文件夹（例如 `target/`、`node_modules/`）不建索引：文件树里只显示它本身，展开时从磁盘现读，模型照样能列出和读写里面的文件；查找和搜索不进入这些文件夹。改了 `.gitignore` 之后，索引会按新的规则重建。

工作区很大时，索引最多记 20 万项（内存紧张时更少），超出的文件夹只记它本身、不进索引；模型查找和搜索的结果会列出这些没进索引的文件夹，并说明结果不完整，这些文件夹可以逐层展开或让模型逐层列出。索引建立失败时，文件树里会写明原因，并有“重建索引”按钮重新建立。

## Shell 与终端

- **PowerShell 与 CMD**：模型运行命令，在“设置 → 环境”里选默认终端。Aura 自带 PowerShell 7。长时间运行的命令可以转到后台，模型之后再查看输出或停止它。
- **终端**：右侧栏可以打开你自己的终端；模型也可以开一个终端交互运行程序，你可以在右侧栏看到它，需要你输入密码等敏感内容时会单独提示。
- **密钥环境变量**：名字里带 `TOKEN`、`KEY`、`SECRET`、`PASSWORD`、`PASS`、`PWD` 等的变量，以及值里带 `用户:密码@` 地址的变量，默认不传给模型运行的命令、终端、Git、MCP、工具包和 Hook。
  - 命令或终端需要其中某些变量时，模型在调用时列出它们的名字（`secret_environment`），只有这些会传过去。只读模式的审批卡片上会列出这些名字。
  - 你环境里所有密钥变量的值都不会出现在模型看到的输出里：命令输出里显示为 `[已隐藏:变量名]`，模型开的终端里显示为同样长度的 `*`。代理变量照常传，只把其中的密码隐藏。
  - 这只防顺手打印：命令有意把值转成别的形式输出、写进文件再读出来或发到网络上，都拦不住；少于 4 个字符的值不隐藏。你自己的终端不受影响。

## Git

使用你自己安装的 Git for Windows（2.40 或更新）。模型可以查看状态、差异和日志，提交、建分支、同步；推送到远程仓库前会先问你。右侧栏的“审查”页显示当前改动。

## 网络

- 网页搜索与抓取、HTTP 请求与下载；
- **内置浏览器**：模型在右侧栏的浏览器里打开网页、点击、输入、截图，用来测试你在做的网页或查资料；你可以随时接手操作。
- **Chrome**：模型操作你在自己的 Chrome 里共享给它的标签页，用的是你已有的登录状态，见 [Chrome 控制](chrome.md)。

## 记忆

Aura 把值得记住的事写成记忆：工作区记忆在工作区的 `.memories` 文件夹，全局记忆在 `%USERPROFILE%\.aura\memories`。“设置 → 记忆”里可以查看、整理和导出。

## 任务方式与命令

在输入框输入 `/` 查看全部命令。常用的有：

- `/plan`：先出方案，你确认后再动手；
- `/goal`：给出一个目标，模型持续工作直到完成或需要你决定；
- `/init`：为工作区生成 `AGENTS.md`，写明项目结构和约定；
- `/compact`：压缩上下文。

你也可以在“设置 → 命令”里保存自己的命令。

## 扩展

- **MCP**：在“设置 → MCP”里接入 MCP 服务器（本地程序或 HTTP），支持 OAuth 登录。服务器的工具在你信任它之后才能使用。
  - GitHub 的 MCP 服务器（`https://api.githubcopilot.com/mcp/`）用个人访问令牌登录：认证选“密钥（Authorization: Bearer）”，填 github.com → Settings → Developer settings → Personal access tokens 里创建的令牌。GitHub 的网页登录要应用自己的客户端密钥，Aura 用不了。
  - 插件里的 HTTP 服务器要登录时，在 MCP 页编辑这个服务器，在认证里选择登录方式并填写密钥，保存后重新信任。
- **Skill**：放在文件夹或 ZIP 里的说明与资料，模型需要时读取。在“设置 → Skill”里导入和信任。导入到 Aura 的 Skill 删除时连同副本一起删除；你自己文件夹（`~/.agents/skills`）或工作区 `.agents/skills` 里的 Skill 删除时，文件夹移到回收站，可以从回收站还原；插件带来的 Skill 随插件删除。
- **插件**：把 Skill、命令、MCP 服务器和 Hook 打包在一起，在“设置 → 插件”里导入。插件带来的每一项都可以在它所在的设置页里单独停用；MCP 服务器还可以编辑配置（改了运行的程序或地址要重新信任），也可以恢复插件的默认配置。它们只随插件一起移除，插件更新时保留你的修改。也能导入 Claude Code 插件：其中的 Skill、命令和 MCP 服务器会使用；Hook、子 Agent、输出样式和语言服务器不使用，导入时逐项列出。
- **工具包**：一组带说明的程序或 HTTP 接口，在“设置 → 工具”的工具包里导入并信任后，模型就能调用。工具包里的程序和模型的命令一样，以你的 Windows 账户运行，不在沙箱里。
- **Hook**：在特定时机（例如写文件之前）运行你的脚本，可以检查或拦下操作。在“设置 → Hook”里管理。

扩展都由你导入并信任，模型不能自己安装或启用它们。
