# 权限模式与审批

每个会话有一个权限模式，在输入框下方切换，也可以输入 `/permission`。

| 模式 | 模型可以直接做的事 |
| --- | --- |
| 只读 | 读取工作区里的文件、搜索、查看 Git 状态等不改动任何东西的操作 |
| 工作区读写 | 再加上在工作区里新建、修改文件 |
| 完全访问 | 不再逐项询问，包括运行命令和访问网络 |

## 运行命令

模型运行的 PowerShell、CMD 命令和它打开的终端以你的 Windows 账户运行，不在沙箱里，能改动工作区以外的文件。

- **工作区读写**：命令直接运行，联网也不问。以下三类除外：
  - **删除文件**的命令（Remove-Item、del、rd、git clean -f、robocopy /MIR 等）：每次都问，只能允许这一次；
  - **下载**的命令：从网上取文件（curl、wget、Invoke-WebRequest、iwr、irm、BITS、certutil 下载）、安装或添加依赖（npm、pnpm、yarn、pip、cargo、winget、choco、scoop 等的 install / add，以及 npx）、拉代码（git clone、pull、fetch）：每个会话问一次，选“本会话内同意”后这个会话里的下载不再询问；
  - **写到工作区以外**的命令：命令文字里写文件、建文件夹、复制或移动的目标，或输出重定向（`>`、`>>`）的目标在工作区以外（包括注册表）：每次都问，只能允许这一次。
- **只读**：每个会话第一次运行命令前会先问你；选“本会话内同意”后，这个会话里的 PowerShell、CMD 和终端都不再询问（重启 Aura、切换模式后仍然有效），新会话会再问一次。命令要联网时另外询问联网；上面三类照工作区读写的规则另问。
- **完全访问**：都不询问。

这些只按命令文字识别。脚本和程序内部做什么（例如 `.\build.ps1`、`python x.py`、`node x.js`、`npm run x`、`make`）看不到，照常运行；命令里用变量拼出来的路径也认不出来。

## 审批

模型想做超出当前模式的事时，会话里会出现审批卡片，写明要做什么、作用在哪里、为什么需要。你可以：

- **同意这一次**：只放行这一个操作；
- **本会话内同意**：同一类操作（同一个文件范围、同一个网站、运行命令）在这个会话里不再询问，重启 Aura 后仍然有效；
- **拒绝**：模型会收到拒绝，并在最后的汇报里说明没做成什么。

删除文件默认放进回收站。不经过回收站的彻底删除每次都单独询问，这次同意不会沿用到下一次：用删除工具彻底删除，在任何模式下都会问；用命令删除文件，除完全访问外都会问（开启完全访问时会提示这一点）。

## 网络

联网工具（网页搜索与抓取、HTTP 请求、内置浏览器）按网站审批。“设置 → 网络与浏览器”里可以管理允许或阻止的网站，以及内置浏览器的调试开关（默认关闭）。

## 工作区以外的文件

模型读写工作区以外的文件需要你逐个同意；你自己拖进输入框、从工作区以外附加的文件，只对这条消息有效。

## 已同意的内容

“设置 → 权限与沙箱”里可以查看和撤销已经给出的会话内同意。
