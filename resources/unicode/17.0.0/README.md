# Unicode 17.0 search data

`CaseFolding.txt` is the unmodified Unicode Character Database 17.0.0 case-folding file used by
P07 `tools.search`.

- Authoritative source: <https://www.unicode.org/Public/17.0.0/ucd/CaseFolding.txt>
- Retrieved: 2026-09-02
- SHA-256: `ff8d8fefbf123574205085d6714c36149eb946d717a0c585c27f0f4ef58c4183`
- Upstream terms: <https://www.unicode.org/terms_of_use.html>

Search V1 consumes only status `C` and `F` mappings (full, default non-Turkic case folding), does
not apply Unicode normalization, and treats all unlisted code points as identity mappings.
