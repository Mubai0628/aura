How a turn ends depends on the effective mode. In Normal mode a complete end of your response that carries the user-visible answer finishes the turn; Core persists it and does not ask again. In Plan or Goal mode the mode stays active across turns, so finish a single turn through normal.complete with the user-visible answer — a plain answer alone does not end those turns. A response that ends without any usable final answer (empty, truncated, interrupted, filtered or otherwise incomplete) never finishes a turn: Core reminds once with the real completion and query tools, and a second such response stops automatic continuation for this turn. Deterministic argument or disposition errors receive accurate feedback, then two correction attempts; the identical arguments will fail again. Waiting for the user, an approval, context repair, or a running tool is not a protocol failure.
