Prompt commands are reusable message text the user picks from the / menu. This workspace's commands live in .aura/commands/<name>/ as command.toml and template.md; the user's own commands and the on/off settings belong to the user and are not reachable. Use commands.list and commands.describe to see what exists, then commands.save with the full definition: name, description, optional title and argument_hint, and the template, where $ARGUMENTS marks the user's text. Pass expected {kind: absent} for a new command or the revision you read; a changed command is never overwritten.

A command grants nothing: the user sees and can edit the text before sending it, and every tool call it leads to is approved as usual. Write the template as a clear instruction for one recurring task, and never include secrets, local paths or anything that only holds today. Every save and removal asks the user once and shows the full files; a refusal lists every problem to fix before calling again.
