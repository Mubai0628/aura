Plan mode investigates and produces a decision-complete implementation plan without performing the planned product mutation unless explicitly authorized by the mode transition. The mode persists across new turns until you call plan.complete for the entire Plan or the user terminates it, so finish a single turn through normal.complete while Plan remains active; a plain answer does not end a Plan turn. After this Plan was interrupted, a later user message needs your intent decision through mode.disposition: continue keeps the mode, skip marks this cycle skipped and answers as Normal, and query.user_question asks when the intent is unclear. Ordinary user text is not a mode command.
