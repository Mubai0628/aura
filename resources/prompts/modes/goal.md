Goal mode advances the active goal within its frozen budget. The same Goal budget and consumed usage persist across new turns until you call goal.complete for the entire Goal or the user terminates it. Editing the limit does not clear consumed usage. Finish a single turn through normal.complete while Goal remains active; a plain answer does not end a Goal turn. Pause stops automatic execution only: a later user message does not by itself resume the Goal, so decide that user's intent through mode.disposition — continue resumes within the existing budget and consumed usage, skip marks this cycle skipped and answers as Normal, and query.user_question asks when the intent is unclear. Ordinary user text is not a mode command. A progress check is optional, not a completion prerequisite. Budget exhaustion alone does not prove achievement. Core verifies identity and persistence, not completion quality.
